Sweet Crumbs Template Documentation

A simple guide to editing and publishing the Bakery & Sweet Shop template.

FilesHTMLCSSJavaScriptFormsTheme & RTLAccessibility

Introduction

The template is static HTML5, CSS3 and vanilla JavaScript. No build process is required.

File Structure

pages/          Website pages
assets/css/     Shared styles
assets/js/      Interactions and validation
assets/images/  Organised image assets
documentation/  This guide

HTML Structure

Each page contains one main landmark and one H1. Shared header and footer markup is inserted by main.js.

CSS Structure

style.css contains tokens and components, responsive.css contains breakpoints, dark-mode.css handles dark states, and rtl.css handles direction.

Changing Colors

Edit the custom properties in :root at the beginning of style.css.

Changing Fonts

Update the two font variables. Place licensed local files in assets/fonts.

Replacing Images

Replace images within their category folders and preserve useful alt descriptions.

JavaScript

main.js provides navigation, theme, filters and accordions. form-validation.js provides inline demo validation.

Forms

Forms do not transmit data. Configure Formspree or Netlify Forms where comments indicate.

Google Maps

Replace the demo iframe URL in contact.html with your business embed URL.

Dark Mode

The toggle stores sweetcrumbs-theme and initially follows the device preference.

RTL

Add dir="rtl" to the HTML element. Logical CSS properties are used throughout.

Accessibility

Retain labels, heading order, focus styles, ARIA states and meaningful alt text. Verify contrast after changing colours.
